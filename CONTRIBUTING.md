# Contributing to ShadowEncoder

Thank you for contributing. Please open an issue before a large change so the scope and user experience can be agreed first.

## Workflow

1. Fork the repository and create a focused branch.
2. Keep the change small enough to review and preserve existing behavior unless the issue requires otherwise.
3. Run the relevant frontend and Rust checks.
4. Describe the behavior change, validation, and any third-party code or assets in the pull request.
5. Accept the CLA below when opening your first pull request.

## CLA acceptance

All contributors must read [CLA.md](CLA.md) and add this exact statement to their first pull request:

> I have read and agree to the ShadowEncoder Contributor License Agreement.

The project may record acceptance in the pull request history. A contribution cannot be merged until acceptance is recorded. Contributors who cannot grant these rights should open an issue before submitting code.

## Third-party material

Do not submit code, media, fonts, models, or other material that you do not have the right to license under the CLA. Identify copied or adapted material and its license in the pull request. Do not commit FFmpeg, mpv, or other runtime binaries to this repository.
