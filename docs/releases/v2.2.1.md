# ShadowEncoder v2.2.1

- 新增序列帧导出，支持 JPEG、PNG、WebP、TIFF、BMP 与 PNG 压缩级别。
- 截图可选择图片格式，并按格式提供质量或压缩参数。
- 新增系统/深色/浅色主题、高对比度与自定义强调色。
- 扩展转码参数、逐帧预览与跨功能页播放器交互。
- 新增 GitHub Release 更新检查，可在应用内查看版本与发布说明。
- 修复原生播放器弹窗遮挡、媒体筛选、输出命名与 Agent CLI 错误反馈问题。
- 转码不再默认添加 `_se` 后缀，同名输出会自动安全避让。

推荐下载 `ShadowEncoder_2.2.1_x64-portable.exe`；也提供 NSIS 与 MSI。
安装包未签名，请对照 `SHA256SUMS.txt` 校验后运行。
