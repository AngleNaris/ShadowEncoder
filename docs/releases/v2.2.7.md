# ShadowEncoder v2.2.7

- 统一界面预览、流程和 CLI 的输出命名，修复文件名含点号时的命名不一致。
- 新增高级自定义节点，可通过 JavaScript 编排素材拼接等预处理；编码格式、质量和音频统一由后续转码节点引用的预设控制，避免重复编码。
- 新增输出设置覆盖节点，可分别覆盖输出目录和命名模板，不修改原编码预设。
- 支持从素材列表拖入独立文件输入节点，以及删除、恢复默认输入节点；缺少必要环节时显示明确错误。
- AI CLI 提供素材节点、脚本写入、输出覆盖和流程校验工具；仓库附带 4K 三格拼接脚本示例。
- 修复精简 CLI 编码预设丢失默认参数、数值字符串导致执行失败的问题。

自定义脚本仅返回 `{ filterComplex, duration }`，视频输出标签为 `[out]`。已有试用脚本若返回格式、编码或输出字段，需要移除这些字段并连接转码节点。

推荐下载 `ShadowEncoder_2.2.7_x64-setup.exe`；也提供 MSI 与便携版。
安装包未签名，可使用 `SHA256SUMS.txt` 校验完整性。
