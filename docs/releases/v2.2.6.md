# ShadowEncoder v2.2.6

- 转码格式选单新增音频输出格式，并会自动隐藏视频编码、分辨率等无关参数。
- 流程系统升级为可连线节点画布，支持类型化端口、并行分支、混音后转码、检测与逻辑分流、文件输出，以及节点内直接编辑参数。
- CLI 新增流程节点与连线创建能力，可构建多规格输出、双目的地 DIT + MD5、代理生成、分辨率分流和失败后继续处理等流程。
- 改进流程画布的拖拽、多选移动、缩放、框选、撤销/重做、连接提示、右键菜单和节点参数展开交互。
- 修复播放器无法随素材列表切换、Tab 切换重置参数、重启保留旧素材列表，以及播放器列无法完全收缩的问题。
- 参数面板支持点击标题折叠，预设管理默认展开；右键菜单增加进入与退出动画。
- 替换 ShadowEncoder 应用图标，并在打包前校验 FFmpeg 9.x 分发输入。

注意：本版本使用新的流程图结构，不迁移旧版流程预设。

推荐下载 `ShadowEncoder_2.2.6_x64-setup.exe`；也提供 MSI 与便携版。
安装包未签名，请对照 `SHA256SUMS.txt` 校验后运行。
