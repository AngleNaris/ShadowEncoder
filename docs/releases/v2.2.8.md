# ShadowEncoder v2.2.8

- **流程高级脚本输入处理**：脚本节点新增「合并输入」（默认）与「分别处理」两种模式。分别处理模式下每个素材逐个执行后续流程图，解决多素材输入被静默截断丢失的问题；合并模式下对已连接但未在滤镜中引用的素材输出黄色预警。
- **素材分组与批次执行**：支持勾选素材后右键「分为一组」，在素材列表中以组标题行与缩进成员展示；各分组按顺序作为独立批次运行整张流程图，未分组素材汇总为最终批次，组内与跨组同名输出自动编号不冲突。
- **列表拖拽排序与交互重构**：素材与分组支持整行拖拽实时排序（组间、组内、顶层及子目录），拖拽过程跟随指针平滑平移并带有行避让过渡，修复尾部素材无法交换问题；成员行支持右键直接移出分组，拖拽时阻止文本选中。
- **素材选择弹窗体验优化**：表头新增三态全选复选框，解决与数据行边框不齐的问题；新增 Shift 区间连选及空白区域鼠标拖拽框选；优化复选框内部对勾居中几何对齐。
- **Agent 状态同步与健壮性**：修复 Agent 外部移除素材时会话分组守卫拦截同步的问题，补齐路径边界匹配与批次推导的 Rust 单测。

推荐下载 `ShadowEncoder_2.2.8_x64-setup.exe`；也提供 MSI 与便携版。
安装包未签名，可使用 `SHA256SUMS.txt` 校验完整性。
