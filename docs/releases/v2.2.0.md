# ShadowEncoder v2.2.0
素材进来，结果出去。一台工作站，一条干净的媒体流程。
- 新增单文件便携版：内含 GUI、Gifski、FFmpeg、FFprobe、libmpv 与 Agent CLI。
- Gifski 静态内置，提供三档体积导向压缩并保留透明 RGBA。
- 新增多目标、MD5 校验、冲突处理完整的 DIT 备份与自动化流程。
- Agent CLI 与 GUI 共享状态，单步修改，保留最近 20 步可撤回操作。
- 统一素材列表、预设管理器、任务进度、日志和播放器交互，并修复 FFmpeg/FFprobe 控制台弹窗。
- 推荐下载 `ShadowEncoder_2.2.0_x64-portable.exe`；也提供 NSIS 与 MSI。
- 安装包未签名，请核对 `SHA256SUMS.txt`；完整改动、构建方法与手动验证边界见 README。
