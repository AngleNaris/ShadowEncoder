# ShadowEncoder v2.2.0

发布日期：2026-07-29

ShadowEncoder 2.2.0 将媒体编码、DIT 数据备份、自动化流程和可撤回的 Agent CLI 集成到同一个桌面工作区。本版本同时完成开源发布所需的许可证、贡献指南和第三方依赖说明。

## 主要更新

- GIF 导出接入 Gifski，采用透明 RGBA 帧管线，提供智能压缩、体积优先和极限压缩三档策略；失败时自动回退到 FFmpeg 调色板编码。
- 新增 DIT 备份：支持多目标复制、扩展名与最小体积过滤、媒体文件过滤、MD5 校验、目录结构保留或塌陷，以及同名不同内容文件的冲突处理。
- 新增 DIT 流程：使用各功能预设编排多步骤任务，支持手动或磁盘接入触发、容量判断、备用目标和步骤失败策略。
- 新增内置 `shadowencoder-cli`：Agent 与可见 GUI 共用本地状态，每条命令只修改一个字段或列表项，并保留最近 20 步可冲突感知撤回操作。
- 素材列表支持目录展开、父子勾选、排序和统一的文件/目录选择体验。
- 统一预设管理器与主界面的字段、禁用状态、列表动画、输入框描边和紧凑布局。
- 改进任务期间的 UI 锁定、进度反馈、日志分组、播放器/日志切换和完成后的输出目录入口。
- 更新弹窗加入 ShadowEncoder 名称、Logo、GitHub 链接和与左上角一致的缓慢放射光束效果。

## 下载

- `ShadowEncoder_2.2.0_x64-setup.exe`：NSIS 安装程序，适合普通安装。
- `ShadowEncoder_2.2.0_x64_en-US.msi`：MSI 安装包，适合需要 Windows Installer 的环境。
- `shadowencoder-cli-2.2.0-windows-x64.exe`：独立 CLI；除 `help` 和 `--version` 外，需要已运行的 ShadowEncoder 2.2.0 应用。
